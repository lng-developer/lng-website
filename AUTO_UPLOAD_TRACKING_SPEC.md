# Auto Upload Tracking System Specification

## Tổng quan
Hệ thống tự động upload tracking batches lên Amazon thông qua extensions. Dựa trên cơ chế auto đã có và logic `checkOrdersStatus` để tìm batches cần upload.

## Kiến trúc

### **Flow tổng quan:**
```
Cron Job (mỗi 3 tiếng) 
  ↓
Find uploadable batches (status: CONFIRM_FILE_READY, chưa upload)
  ↓
Group batches theo machineId (shopId = machineId)
  ↓
Tạo file content + task payload cho từng batch
  ↓
Gửi UPLOAD_TRACKING task qua Socket.IO đến đúng extension
  ↓
Đánh dấu batch đã upload + Log vào database
```

## Components

### 1. **ConfigAuto Model** (Updated)
```javascript
{
  id: "auto-upload-tracking",
  type: "uploadTracking",
  autoTime: "0 */3 * * *", // Mỗi 3 tiếng
  status: true,
  config: {
    maxBatches: 20,              // Tối đa 20 batches/lần
    dryRun: false,               // false = thực tế upload
    carrierCode: "USPS",         // Carrier mặc định
    shipMethod: "USPS First Class" // Ship method mặc định
  }
}
```

### 2. **Controller Function**
**File:** `src/controllers/shippingBatch.contrller.js`
**Function:** `autoUploadTracking`

**Logic:**
1. **Find uploadable batches:**
   ```javascript
   {
     status: 'CONFIRM_FILE_READY',
     completed: { $exists: true, $ne: [] },
     uploadTaskSent: { $ne: true },
     machineId: { $exists: true, $ne: null }
   }
   ```

2. **Group theo machineId:** Đảm bảo gửi đúng extension của từng shop

3. **Tạo task payload:**
   ```javascript
   {
     type: "UPLOAD_TRACKING",
     payload: {
       batchId, machineId, shopId: machineId,
       trackingData: [...],
       file: { filename, content, contentType, size },
       uploadParams: { carrierCode, shipMethod, shipDate },
       autoGenerated: true,
       reason: "auto_upload_tracking"
     }
   }
   ```

4. **Gửi qua Socket.IO:** `io.to(\`machine:\${machineId}\`).emit("server:task", task)`

5. **Update database:** Đánh dấu `uploadTaskSent: true`

## Key Features

### **1. Intelligent Batch Selection**
- Chỉ upload batches có `status: CONFIRM_FILE_READY`
- Có `completed` data (orders với tracking)
- Chưa gửi upload task (`uploadTaskSent != true`)
- Có `machineId` (để biết gửi đến extension nào)

### **2. Shop-Specific Routing**
- **shopId = machineId** (quan trọng!)
- Group batches theo machineId để gửi đúng extension
- Mỗi extension chỉ nhận batches của shop mình

### **3. File Generation**
- Tạo file content TSV format giống manual upload
- Include tracking data, carrier info, ship date
- Filename format: `auto_upload_{batchId}.txt`

### **4. Socket.IO Integration**
- Sử dụng Socket.IO instance thực tế từ server
- Gửi đến room cụ thể: `machine:{machineId}`
- Task type: `UPLOAD_TRACKING` (giống manual)

### **5. Database Tracking**
- Đánh dấu batch đã upload: `uploadTaskSent: true`
- Log vào `RealtimeLog` để audit
- Stats tracking trong `AutoJobLog`

### **6. Error Handling**
- Graceful handling khi Socket.IO không available
- Individual batch error không ảnh hưởng toàn bộ
- Detailed logging cho debugging

### **7. Dry Run Support**
- Test mode không update database
- Useful cho debugging và testing
- Configurable qua config hoặc API call

## Configuration

### **Cron Schedule**
- **Default:** `0 */3 * * *` (mỗi 3 tiếng)
- **Customizable:** Có thể thay đổi qua ConfigAuto

### **Batch Limits**
- **Default:** 20 batches/lần
- **Rationale:** Tránh overload extensions và network

### **Carrier Settings**
- **Default:** USPS, USPS First Class
- **Configurable:** Có thể override qua config hoặc API

## Monitoring & Debugging

### **1. AutoJobLog Database**
- Mỗi execution tạo log entry
- Chi tiết từng bước: find batches → process → send tasks
- Stats: processed, success, failed counts
- Error tracking với stack trace

### **2. RealtimeLog**
- Log cho từng batch được upload
- Include shop info, tracking count, filename
- Level: info, action: auto

### **3. API Endpoints**
```
GET /api/auto-job-logs?jobType=uploadTracking
GET /api/auto-job-logs/stats?jobId=auto-upload-tracking
GET /api/auto-job-logs/export?jobId=auto-upload-tracking
```

## Integration với Extensions

### **Task Format**
Extensions nhận task với format:
```javascript
{
  type: "UPLOAD_TRACKING",
  payload: {
    batchId: "69d7b0e0014087216b853d12",
    machineId: "6881aba9c1bbdfc541b5cd4d",
    shopId: "6881aba9c1bbdfc541b5cd4d",
    label: "Auto Upload Batch",
    trackingData: [
      {
        orderId: "113-1234567-8901234",
        tracking: "1Z999AA1234567890",
        isFake: false,
        source: "system"
      }
    ],
    file: {
      filename: "auto_upload_69d7b0e0014087216b853d12.txt",
      content: "order-id\torder-item-id\ttracking-number\tcarrier-code\tship-method\tship-date\n...",
      contentType: "text/tab-separated-values; charset=utf-8",
      size: 2048
    },
    uploadParams: {
      carrierCode: "USPS",
      shipMethod: "USPS First Class", 
      shipDate: "2026-04-09"
    },
    autoGenerated: true,
    reason: "auto_upload_tracking",
    timestamp: "2026-04-09T15:23:21.814Z"
  }
}
```

### **Extension Processing**
1. Nhận task từ Socket.IO
2. Parse file content
3. Upload lên Amazon Seller Central
4. Report back status (optional)
